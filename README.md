# Zingoo – Social Media Web Application

Zingoo is a full-stack social media web application developed using modern web technologies.

## Features
- User registration and login
- Social media feed
- Frontend and backend integration
- Supabase authentication and database services

## Technologies Used
- React
- TypeScript
- Node.js
- Express.js
- Supabase
- Vercel
- Render
